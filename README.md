# RESQ AI — Intelligent Autonomous Rescue Agent Using Reinforcement Learning

A university CCP starter implementation using Python, Pygame, Streamlit and PyTorch.

## Important scope notes

- The Pygame renderer is the simulation visualization engine; Streamlit embeds its rendered output.
- The environment uses a partially observable local 5×5 observation plus compact resource/mission features.
- The learning agent is Double DQN with experience replay and a target network.
- Random and Rule-Based baselines are included.
- Training and evaluation write CSV files from actual executions.
- This is an academic simulation, not a real emergency-response tool.
- The initial environment and reward values are experimental starting points and should be validated/tuned.

## 1. Install software

Install:
1. Python 3.10 or 3.11 (64-bit).
2. Visual Studio Code.
3. VS Code Python extension.

Open the `RESQ_AI` folder in VS Code.

## 2. Create a virtual environment (Windows PowerShell)

Open Terminal > New Terminal in VS Code and run:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, run this once in the terminal:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

If `py -3.11` is unavailable, use `py -m venv .venv` with an installed supported Python version.

## 3. Select the interpreter

In VS Code:
1. Press `Ctrl + Shift + P`.
2. Search `Python: Select Interpreter`.
3. Select the interpreter inside `RESQ_AI\.venv`.
4. Open a new terminal and confirm `(.venv)` appears.

## 4. Run the dashboard

```powershell
streamlit run app.py
```

Streamlit will show a local URL, usually `http://localhost:8501`.

Pages:
- Mission Control
- Live Simulation
- RL Training Lab
- Agent Performance
- Environment Configuration
- Project / About

## 5. Train the Double DQN agent

Start with a short pilot:

```powershell
python training/train.py --episodes 50
```

Then, if the run works and the computer has sufficient resources:

```powershell
python training/train.py --episodes 500
```

Training history is saved to:
`data/training_logs/training.csv`

Best model:
`models/best_model/resq_double_dqn.pt`

Latest model:
`models/checkpoints/latest.pt`

Training can also be started from the RL Training Lab page. It runs in a separate process. Refresh the page to update charts.

To resume from a checkpoint:

```powershell
python training/train.py --episodes 500 --resume models/checkpoints/latest.pt
```

Note: the CSV episode counter starts again for each new process; keep separate log files for separate formal experiments if you need clean experiment accounting.

## 6. Evaluate all agents

First train a model. Then run:

```powershell
python evaluation/evaluator.py --episodes 30
```

Results are saved to:
`data/evaluation_results/comparison.csv`

The evaluator uses the same evaluation seed set for each agent. A missing checkpoint means the DQN row represents an untrained network; do not interpret that as trained RL performance.

## 7. Run tests

```powershell
python -m pytest -q
```

## 8. Suggested development workflow

1. Run tests.
2. Open Mission Control.
3. Open Live Simulation and try Manual mode.
4. Try Random and Rule-Based modes.
5. Run a short 50-episode training pilot.
6. Inspect reward and rescue curves.
7. Run evaluation after training.
8. Save the configuration and results for the academic report.

## 9. Hardware guidance

The project is designed to run on CPU with a small MLP. GPU is optional. Start with 50–100 episodes and monitor CPU/RAM before increasing the episode count. The appropriate training duration depends on the actual CPU, RAM and runtime.

## 10. Troubleshooting

### `streamlit` is not recognized
Activate `.venv`, then run:
`python -m streamlit run app.py`

### `ModuleNotFoundError`
Confirm the `.venv` interpreter is selected and run:
`pip install -r requirements.txt`

### Pygame display / SDL issue
The renderer uses an off-screen Pygame surface and sets the dummy SDL video driver. Do not launch a separate Pygame window for the Streamlit integration.

### PyTorch installation is slow
PyTorch is the largest dependency. Allow the installation to finish. CPU training is supported.

### PowerShell activation issue
Use the process-scoped execution policy command in section 2. It does not permanently change the machine-wide policy.

## 11. Academic integrity and experimental reporting

Never report illustrative dashboard values as results. Report only values generated by training/evaluation runs. Record:
- scenario configuration and seed,
- number of training episodes,
- model checkpoint,
- evaluation seeds,
- agent metrics,
- known limitations.

The current rule-based baseline is a simple heuristic and the reward function is a starting point. Analyze results honestly and improve the environment/agent based on evidence.
